# Multi Tool（PC 向け・自分用）

`Multi Tool.html` 単体で動作します（外部ライブラリなし、3D は自前の WebGL2 描画）。

## 機能
- **油圧シリンダ推力**：内径・ロッド径・圧力（MPa / bar / kgf/cm² / psi）から押し力・引き力、背圧・効率・本数、流量からの速度・戻り流量、必要圧力の逆算、圧力別推力表
- **エンジン音 周波数**：サイクル・気筒数・回転数から回転1次／0.5次／爆発一次と高調波、ファン・ポンプ・ギヤなどの追加成分、キャンベル線図、測定周波数→回転数の逆算、確認用の合成音
- **FFT解析（試作）**：音声・動画ファイル（音声トラック）または CSV（振動データ等）を読込み、区間指定した平均スペクトル・スペクトログラム・ピーク一覧。エンジン音タブの計算周波数を重ねて表示
- **3D 油圧ショベル**：キーボード／画面ボタンで操作（ISO パターン：WASD＝左レバー、矢印＝右レバー、Q/Z＝左走行、E/C＝右走行）。
  寸法入力でモデル再生成、姿勢の数値指定、シリンダ長表示、側面・上面などの正投影、
  線画（取説風）・黒シルエット表示、PNG 保存（透明背景可）、設定の JSON 保存/読込
